律所办公系统 · 数据分析智能体 · 在线演示

向律所数据提任何问题——
但只看到你有权看的。

LawX 是面向中小型律所的办公系统：案件、客户、收费账务、工时与法律资料库， 配套标准经营报告和智能助手——它能分析律所数据库、生成带图表的报告、解答法律问题。 每一次查询都以提问者本人的身份执行：律师只看到自己的案件，合伙人看到团队，管理层看到全所——由数据库本身强制保证。

痛点

中小律所靠表格和微信群运转：合伙人看不清经营状况，通用 AI 又无法放心交给客户数据。

📂

数据分散

案件、收费协议、发票、工时散落在不同文件里，没人说得清回款率，也不知道哪个获客渠道最有效。

🔐

保密要求严格

律师只能看自己的客户，合伙人看团队，薪酬只有本人和管理员可见。任何工具都必须遵守——AI 也不例外。

🤖

AI 缺少约束

把律所数据贴进聊天机器人既有泄露风险，结果也无从核实。律所需要基于自身数据库、可追溯的答案。

产品

一个中英双语的 Web 应用，服务律师、合伙人与管理员。

办公核心

案件（团队与进展）、客户（获客渠道）、收费协议（固定、计时、风险代理、混合）、发票、回款、工时、法律资料库。

标准报告

客户分析、收入与应收账龄、收结案与结案结果、工作量——任意期间、按查看者权限、可导出 PDF。

智能助手

用自然语言提问：它会查询数据库、生成带图表的自定义报告，或引用本所资料库解答法律问题。

AI 也无法绕过的权限体系

权限 = 模块 + 操作 + 数据范围。数据范围依据律所组织架构；PostgreSQL 行级安全过滤每一次查询——无论来自网页还是智能助手。

范围含义典型角色
own与我相关的记录（我的案件、客户、工时）律师
team我 + 所有向我汇报的人合伙人
department团队 + 我负责部门的所有人部门负责人
all全所管理层 / 管理员
角色可配置，无需改代码。

在管理后台新建“律师助理”“财务”等角色；还可对个人单独提高或收回某项权限。

敏感数据默认保护。

薪酬仅本人与管理员可见；公开案例隐藏客户信息；应用本身也读不到密码哈希。

全程审计。

每次修改、登录、薪酬查看与智能助手查询都有记录，含修改前后的值。

智能助手如何工作

大模型 + 四个工具——全部以用户身份执行，全部留痕。

1
query_database

在精选、去除敏感列的视图上编写单条 SELECT，结果已按用户权限过滤。

2
run_standard_report

问题与标准报告相符时，直接使用经过校验的报告口径。

3
search_law_library

法律解答以本所收录的法律、司法解释与案例为依据。

4
create_report

生成含指标、图表、表格的报告；有错误的报告会被退回修正，绝不半成品保存。

模型与数据之间的四道防线

  1. SQL 校验：仅允许单条 SELECT、仅限授权视图、函数白名单（无法切换身份）；执行的正是校验通过的语句。
  2. 受限数据库角色，只能读取精选视图。
  3. 只读事务，单条查询 10 秒超时。
  4. 用户本人的行级安全策略。

模型只会收到用户本人提问所检索到的数据。支持任意 OpenAI 兼容的大模型——DeepSeek、通义千问、智谱 GLM、Kimi，私有化部署也可使用本地模型。管理员可在“智能体监控”中查看每一段对话，被拦截的查询会被标红。

一套代码，两种部署

两种方式下每家律所都有独立数据库——隔离彻底，导出简单。

云端（SaaS）私有化部署
托管中心服务器，每家律所独立数据库律所自有服务器，数据自持
开通注册即用一条命令安装，浏览器中完成初始化向导
更新由我们持续更新管理后台一键更新：自动备份数据库 → 构建 → 健康检查 → 失败自动回滚
AI 模型托管大模型，按律所计量律所自有 API 密钥，或本地模型
